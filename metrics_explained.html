ML Metrics — Visual Guide

What each metric measures, what "good" looks like, and which one to use when

🗺️ Which Metric for Which Fine-Tuning Type?

FT TypeMetricGoodWhy This Metric?
📝 Text FTLoss< 1.0"Was the next word right?" — cross-entropy over vocabulary
📊 Tabular FTLoss< 1.0Same as text — rows become sentences, then predict
🖼️ Image FTmAP> 0.7"Is the box on the right object?" — overlap + classification
🖼️📝 Vision-LangLoss< 1.0Same as text — the output is text (medical answer)
🔧 Sensor FTLoss< 1.0Same as text — vibrations become sentences, then predict
🧪 Testing (6A)Accuracy> 85%"Did it answer the test questions correctly?"
📊 Monitoring (6B)Drift< 0.2"Are users asking about new topics we never trained on?"
🚀 Deploy (LLM)Perplexity< 3.0"How confident is the model?" = exp(loss)
🚀 Deploy (Vision)mAP + FPS> 0.7, >30Accuracy + real-time speed requirement
🧠 Key insight: 5 of 7 fine-tuning types use Loss because they output TEXT. Only Image FT uses mAP because it outputs BOUNDING BOXES. In production, switch to Drift to know WHEN to retrain.
