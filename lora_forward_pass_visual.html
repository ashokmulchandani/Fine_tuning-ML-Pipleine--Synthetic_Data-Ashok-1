3. Why LoRA Adds Almost No Cost

OperationMultiplications% of Total
W_q · x (frozen Q)4096 × 4096 = 16,777,21699.6%
A_q · x (LoRA step 1)8 × 4096 = 32,7680.2%

Total Q path16,842,752100%

LoRA adds only 65K operations to the 16.8M operations of the frozen Q. That's 0.4% overhead. Across all 32 layers with Q+V adapters, total overhead stays under 1%.

The Two Rules of LoRA Forward Pass

Rule 1: A × x runs FIRST (cheap, only 8 dimensions). Then B × (A×x) runs (cheap, only 8 dimensions). B×A is NEVER computed as a full matrix. It's always done in two cheap steps.

Rule 2: The LoRA adapter for Q in layer 3 is different from the LoRA adapter for Q in layer 15. Every layer learns different things. Layer 3 adjusts grammar. Layer 28 adjusts style. They need different B and A matrices.
