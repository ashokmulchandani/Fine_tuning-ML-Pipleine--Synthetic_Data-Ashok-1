Step 3: Project to LLM Space — 1024 → 4096

A simple linear projection layer maps each 1024-dim visual token to 4096-dim — matching the LLM's input size. Think of it as a translation layer between vision and language.

197 tokens × 1024-dim → Linear Projection
1024×4096 matrix (4.2M params, FROZEN) → 197 tokens × 4096-dim
🧠 Why 4096? Because the LLM (Llama-7B) expects 4096-dimensional input. Everything must match: word embeddings are 4096-dim, so visual tokens must also be 4096-dim to be processed together. The projection layer is the "bridge" between the vision world (1024-dim) and the language world (4096-dim).
↓

Step 4: Combine Visual + Text → One 512-Token Sequence

The 197 visual tokens are prepended to the text tokens. The LLM sees them as one continuous sequence. It doesn't know which tokens came from the image and which from the text.

197 visual tokens + 315 text tokens = 512 total tokens, each 4096-dim
