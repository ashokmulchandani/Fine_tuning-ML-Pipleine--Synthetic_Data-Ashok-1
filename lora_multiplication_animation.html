Step 1: A × x — Multiply the LoRA matrix A (r×d) with input x (d×1). This is CHEAP because r is tiny (r=8 in real model, shown as r=2 here). Result: r numbers.
🧠 Key: B×A is NEVER computed as a full matrix. Always two cheap steps: A·x first (a few ops), then B·(A·x) (a few more ops). Total LoRA cost = 0.4% of W·x.
